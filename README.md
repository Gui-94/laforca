# Jogo da Forca

Este é um projeto de **Jogo da Forca** feito com **HTML, CSS e JavaScript puro**, ideal para quem está aprendendo programação web.

---

## Estrutura do Projeto


- **css/forca.css**: Contém o estilo do jogo.  
- **js/forca.js**: Contém toda a lógica do jogo (verificação de letras, desenho da forca, vitória e derrota).  
- **img/**: Todas as imagens usadas no jogo, incluindo a forca, personagens e fundo.  

---

## Como Executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no seu navegador.
3. Comece a jogar!

---

## Funcionalidades

- Adição de palavras e letras.
- Desenho da forca conforme erros do jogador.
- Mensagens de vitória ou derrota.
- Botão de "Jogar Novamente".

---

## Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**

---

## Observações

Este projeto é ótimo para iniciantes praticarem manipulação do DOM, lógica de programação e eventos em JavaScript.
